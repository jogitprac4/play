# GETHU Public Pages

Static public pages for GETHU.

## URLs

- /
- /privacy
- /data-protection
- /security
- /terms
- /community-guidelines
- /account-deletion
- /contact

## Local testing

From this folder, run:

    python -m http.server 8000

Then open:

    http://localhost:8000/

The site is structured for Cloudflare Pages deployment. Each public path has its own `index.html`.
