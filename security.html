GETHU Security

Last updated: August 20, 2026

GETHU takes the security of its application and user information seriously.

Security Practices

  • Authentication and authorization controls are used to restrict access to protected functionality.
  • Secure transport is used for supported network communications.
  • Access to production systems is restricted to authorized personnel and services.
  • Application and infrastructure components are monitored and maintained as appropriate.
  • Security issues are investigated and addressed based on their severity and potential impact.

Responsible Security Reporting

If you believe you have discovered a security vulnerability affecting GETHU, please report it responsibly rather than publicly disclosing exploit details.

Please include enough information for us to understand and reproduce the issue, including the affected feature, steps to reproduce, and any relevant evidence.

Report a Security Issue

Email: support@gethu.app

Please do not include passwords, authentication tokens, or unnecessary personal information in a security report.

For information about how user data is handled, see the Privacy Policy and Data Protection page.
